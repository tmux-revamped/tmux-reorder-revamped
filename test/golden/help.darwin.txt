$ reorder-revamped help
reorder-revamped - drag a window tab along the tmux status line to move it

usage:
  reorder-revamped apply     bind the status line mouse keys now
  reorder-revamped list      print every binding apply would make
  reorder-revamped grab SESSION CLIENT
                             measure the tabs when a drag starts
  reorder-revamped slide SESSION SOURCE TARGET CLIENT MEASURE
                             move the dragged window onto a tab while
                             dragging
  reorder-revamped drop SESSION SOURCE:SEEN TARGET ACTIVITY
                             move the dragged window onto the tab it was
                             released on
  reorder-revamped edge first|last|trailing SESSION SOURCE:SEEN ACTIVITY
                             move the dragged window to an end of the list
  reorder-revamped doctor    check this machine
  reorder-revamped version   print the version
  reorder-revamped help      print this page

options:
  --json           list prints one JSON object
  --theme NAME     the look: kodougu, catppuccin-mocha, catppuccin-latte,
                   dracula, nord, gruvbox, tokyo-night or mono
  --SETTING VALUE  any tmux option below, named with dashes, such as
                   --mode swap or --edges off

environment:
  REORDER_REVAMPED_SETTING  any tmux option below in capitals, such as
                            REORDER_REVAMPED_MODE
  REORDER_REVAMPED_THEME    the look, when --theme is not given
  REORDER_REVAMPED_ACCENT   a colour such as #CBA6F7 for the accent
  KODOUGU_THEME             the family look, when neither is given
  KODOUGU_ACCENT            the family accent, when the tool's is unset
  NO_COLOR                  turn colour off

tmux options:
  @reorder_revamped_mode            insert shifts the tabs in between, swap
                                    exchanges two windows on release (insert)
  @reorder_revamped_live            off moves the window only on release (on)
  @reorder_revamped_edges           off leaves status-left, status-right and
                                    the empty space unbound (on)
  @reorder_revamped_timeout         seconds after which a recorded drag is
                                    ignored (10)
  @reorder_revamped_enable_logging  1 writes failed moves to a log (unset)
  @revamped_theme                   the family look (kodougu)

notes:
  The entry point runs apply once when tmux loads the plugin, and every
  binding goes to tmux in one call. The first motion of a drag records the
  pressed tab with set-option -F, which starts no process; grab, slide, drop
  and edge run from the mouse bindings. A drag counts only when it began with
  a press on a tab within the last 10 seconds. A mode or timeout given to
  apply on the command line or in the environment rides on the drop and edge
  bindings; one set as a tmux option is read again when each drag ends.
  Needs tmux 3.2.

examples:
  reorder-revamped list
  reorder-revamped --mode swap apply
  reorder-revamped doctor
exit 0
